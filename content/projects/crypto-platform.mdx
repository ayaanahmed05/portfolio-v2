### Overview
Served as Team Lead for a real-time cryptocurrency trading simulation platform built to model live market environments without financial risk. The project combines high-throughput event-driven system design with a modern frontend to deliver low-latency order execution, live portfolio tracking, and interactive strategy analytics.

### Key Features & Engineering

* **Engineering Leadership:** Directed a team of 5 developers through system design, task distribution, and code reviews to deliver an end-to-end trading platform.
* **Event-Driven Architecture:** Designed a real-time WebSocket communication pipeline to process high-frequency transaction updates and synchronize live market states across concurrent client sessions.
* **Analytics Dashboard:** Built an interactive React frontend featuring real-time portfolio performance tracking, trade execution logs, and detailed visual metrics.
* **Data & State Management:** Modeled robust SQL schemas to reliably track user account balances, position histories, and transactional audits under real-time conditions.
