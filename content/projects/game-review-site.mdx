### Overview
Engineered a classic full-stack web platform designed to streamline video game discovery and user-generated review management. Recognized in the top 10 projects of the course cohort, the platform pairs secure PHP backend processing with dynamic JavaScript features to deliver a responsive, community-driven review system.

### Key Features & Engineering

* **Course Recognition:** Named a top-10 project in a cohort-wide evaluation for usability, clean interface design, and overall technical execution.
* **Server-Side Logic:** Built PHP backend routes to handle user authentication, review creation, form submission processing, and relational data retrieval.
* **Client-Side Interactivity:** Implemented native JavaScript to deliver real-time form validation, dynamic DOM updates, and responsive navigation without full page reloads.
* **User Interface & Design:** Authored semantic HTML5 and custom CSS stylesheets to create an accessible, user-friendly layout for browsing and filtering game catalogs.
* **Version Control & Collaboration:** Maintained clean repository organization and modular code architecture using Git and GitHub.
