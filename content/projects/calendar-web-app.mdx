### Overview
Engineered a responsive calendar web app focused on core DOM manipulation, date arithmetic, and client-side storage mechanics. Built entirely without external frameworks, the app provides a lightweight interface for scheduling events, tracking dates, and persisting user data directly in the browser.

### Key Features & Engineering

* **Client-Side Persistence:** Integrated browser LocalStorage to serialise user event data, ensuring schedules persist across page refreshes and browser sessions without an external database.
* **Dynamic Calendar Engine:** Implemented native JavaScript logic to calculate date boundaries, handle month/year transitions, and render custom calendar grids dynamically.
* **Interactive Event Workflows:** Designed responsive modal forms and event listeners to let users seamlessly add, view, and organize scheduled items in real time.
* **UI & Responsive Layouts:** Authored custom CSS using Flexbox and CSS Grid to deliver a clean, modern interface adapted for varying viewport sizes.
* **Version Control:** Tracked project updates and modular feature iterations using Git and GitHub.
